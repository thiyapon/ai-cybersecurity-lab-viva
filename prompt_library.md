# Prompt Library

## P1 — Syllabus-grounded summary
Using only the supplied cybersecurity lab material, summarize the aim, theory, prerequisites, procedure, expected observations and safety precautions. Preserve technical terms. If information is missing, write “Not specified in the source.” Do not invent procedures. Include page/section pointers when available.

## P2 — Viva question generation
Generate exactly 10 viva questions from the supplied lab topic: 3 basic, 4 intermediate and 3 application-based. Provide concise model answers and identify which supplied source supports each answer. Do not invent citations. Mark unsupported claims as “Needs verification.”

## P3 — Answer verification
Compare each model answer with the supplied course material and current official reference. Label it Verified, Corrected or Unresolved. Identify supporting evidence, explain errors, and provide a corrected answer. If evidence is insufficient, do not guess. A second AI response alone is not authoritative evidence.

## P4 — Interactive viva practice
Act as a cybersecurity lab examiner. Ask one question at a time from the verified question bank. Wait for my answer, assess technical accuracy against the approved answer key, award a score out of 5, explain missing points, and continue. Accept technically correct alternative wording.

## P5 — Flashcard generation
Convert the verified question bank into concise front/back flashcards. Keep one concept per card. Do not add facts that are absent from the verified source.

## P6 — Presentation outline
Create a 6-slide presentation: problem, objectives, topics and tools, system workflow, prototype and testing, responsible AI and conclusion. Keep slide text concise and suggest one visual per slide. Do not invent testing results.

## P7 — Error audit
Review the AI-generated output for incorrect, incomplete, ambiguous or unsupported technical claims. Return a table with claim, risk, evidence needed, status and recommended correction.
